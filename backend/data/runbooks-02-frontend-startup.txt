RUNBOOK: FRONTEND STARTUP
============================

Prerequisites:
- Python 3.12+ installed
- Virtual environment created: python -m venv .venv
- Dependencies installed: pip install -r requirements.txt
- Environment variable BACKEND_URL configured in frontend/.env (default: http://localhost:8000)
- Backend service already running and reachable at BACKEND_URL

Step-by-Step Startup:
1. Navigate to frontend directory: cd frontend
2. Activate virtual environment: .\.venv\Scripts\Activate.ps1
3. Start the app: streamlit run app.py
4. Confirm the browser opens automatically to http://localhost:8501, or navigate there manually.
5. Send a test message in the chat interface and verify a response is returned.

Expected Output:
- Streamlit prints "You can now view your Streamlit app in your browser" with a local URL.
- The chat interface loads with an empty conversation history.
- A test message receives a response within a few seconds.

Troubleshooting:
- If the app loads but chat requests fail, verify the backend is running and BACKEND_URL matches its address.
- If the browser shows a connection refused error, confirm no firewall is blocking port 8501.
- If styling looks broken after an update, clear the Streamlit cache with the "Clear cache" option in the app menu.

Stopping the App:
Press Ctrl+C in the terminal running Streamlit to stop the process cleanly.
