POLICY: MODEL USAGE AND AI GOVERNANCE
========================================

Policy ID: POL-AI-010
Effective Date: 2026-04-01
Owner: Engineering Team
Review Cycle: Annual

Purpose
-------
Sets expectations for how LLMs are selected, prompted, and monitored within the multi-agent system to ensure grounded, safe, and cost-effective responses.

Scope
-----
Applies to the Supervisor, Retrieval, Research, and Response agents, and any future agents added to the LangGraph workflow.

Policy Statements
------------------
1. The Response Agent must ground its answers in retrieved context whenever relevant documents are available, and must clearly indicate when it is answering without supporting context.
2. The Research Agent is capped at a fixed maximum number of refinement iterations to bound latency and cost; this limit is defined as a constant in code and must not be changed without review.
3. Model temperature and other generation parameters must be set explicitly in configuration rather than left to provider defaults, so behavior is reproducible.
4. Prompts used by any agent must be version-controlled alongside the code that uses them, not stored only in a runtime configuration.
5. Any change to system prompts that could affect response tone, safety, or accuracy must be reviewed by at least one other engineer.
6. The system must not be used to generate content that violates OpenRouter's or the underlying model providers' acceptable use policies.
7. Periodic spot checks of agent responses should be performed to catch hallucination, prompt injection susceptibility, or routing errors.

Enforcement
-----------
Prompt and agent configuration changes are reviewed as part of standard code review. Spot-check findings are logged and addressed in the following sprint.
